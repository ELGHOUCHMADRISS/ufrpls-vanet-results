§1 Network Topology & Architecture

File: simulations/vanet/ufrpls/UFRPLSSim.ned (50 lines)

1.1 Overview

UFRPLSSim.ned declares the single shared network topology used by every simulation configuration. It is declared under OMNeT++ package vanetsim.simulations.vanet.ufrpls and every named configuration in the .ini file sets network = UFRPLSSim.

The design is deliberately minimal: it provides only the structural scaffold (radio medium, mobility manager, node placeholders), while the .ini file and SUMO supply all concrete parameters and vehicle trajectories.

3.3 SUMO Launch & Failure Recovery

def start_launchd():
    cmd = [PYTHON2_EXE, LAUNCHD_PY, "-vv", "-c", SUMO_EXE, "--port", "9999"]
    proc = subprocess.Popen(cmd)
    if wait_for_port(9999, timeout=20):   // poll 0.5s intervals
        return proc       // sumo-launchd ready to accept TraCI connections
    return None            // abort batch if not up in 20s
Failure Recovery After any OMNeT++ run that returns a non-zero exit code, the script stops sumo-launchd, sleeps 2 seconds, and restarts it. This is necessary because a SUMO crash leaves sumo-launchd.py in a broken state causing WSAECONNRESET (10054) on the next TraCI connection attempt.

3.4 Eavesdropper Position Injection

Vehicle[0] is the eavesdropper. Its road starting position (departPos) is set by patching the SUMO route XML before each OMNeT++ run:

def route_file_for_config(config_name):
    veh    = re.search(r"(?:UFRPLS|GPSRCS)-(\d+)veh", config_name).group(1)
    is_fast = config_name.endswith("-fast")
    speed  = "80-120kmh" if is_fast else "40-60kmh"
    return MAPS_PLS_DIR + f"/traffic_{veh}veh_{speed}_rou.xml"

def set_eavesdropper_position(route_file, new_pos):
    pattern = re.compile(
        r'(<vehicle\s+id="vehicle00"[\s\S]*?departPos=")(\d+(?:\.\d+)?)(")' 
    )
    // Replace departPos value; [\s\S]*? matches across newlines (dotall, non-greedy)
    new_content, count = pattern.subn(rf'\g<1>{round(new_pos,1)}\g<3>', content, count=1)
    with open(route_file, "w") as f: f.write(new_content)

§5 Core Project Metrics Location

All metrics are emitted as OMNeT++ signals in the routing modules (UFRPLS.cc / GPSRCS.cc) and recorded as scalars in the .sca file. Because **.vector-recording = false, only aggregate values (mean, min, max, count) are stored — not per-event time series.

Secrecy Capacity (CS)
Signal: csSignal (both protocols) C_ij = log₂(1 + Pt·(λ/4πd)²/σ²) CS_ij = max(C_ij − max_e(C_ie), 0)

.sca key: secrecyCapacity:mean / :max / :min

Emitted per forwarding hop. In UFRPLS it drives routing; in GPSRCS it is measured after the distance-based decision.

Min CS Per Packet
Signal: minCsPerPktSignal min CS across all hops of one delivered packet

.sca key: minSecrecyCapacityPerPacket:mean

Worst-case security along the entire path. Always ≥ 0 in UFRPLS; can be 0 in GPSRCS.

Packet Delivery Ratio (PDR)
INET app module scalars (no custom signal) PDR = packetReceived / packetSent

.sca: vehicle[1].app[0] packetSent:count
vehicle[N-1].app[0] packetReceived:count

Drop causes: UFRPLS — wait timeout (65ms); GPSRCS — immediate no-route drop.

End-to-End Delay
Signal: delaySignal delay = simTime() − pkt.creationTime()

.sca key: endToEndDelay:mean / :max / :min

Measured at destination routing hook. Includes queuing, MAC backoff, propagation, and UFRPLS backoff waiting.

Hop Count Metrics
finish() scalars (not signals) secureHopRatio = secureHops / totalHops

.sca: totalHops, secureHops, secureHopRatio,
globalEavesdropperCount

UFRPLS secureHopRatio ≈ 1.0 (zero-CS hops blocked). GPSRCS may have ratio < 1.0.

Drop Causes
INET drop counters + routing module UFRPLS: drop if totalWaited > 65ms, no secure hop GPSRCS: immediate drop if no greedy/perimeter hop

.sca: droppedPackets:count (routing)
ipv4.ip.droppedPkNoRoute:count

PDR loss = 1 − PDR; reveals routing protocol effectiveness under eavesdropper interference.
