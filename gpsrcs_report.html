GPSRCS Protocol

GPSR Baseline with post-hoc Physical Layer Security Measurement
Author: EL-GHOUCHMA DRISS INET 4.x / OMNeT++ 6.x vanetsim.routing.gpsrCS Date: 2026-07-01

⚡Protocol Design Intent

GPSRCS is the baseline comparator for UFRPLS research. Routing decisions are made using pure geographic distance — the same algorithm as standard GPSR (greedy forwarding with perimeter fallback). After each hop is selected, Secrecy Capacity (CS) is computed post-hoc as a passive observer metric that has zero influence on routing.

Key design principle: By using identical PLS measurement code in both GPSRCS and UFRPLS but letting UFRPLS use CS to drive routing, the experimental comparison isolates exactly the benefit of the utility-function approach.

Called by: findPerimeterRoutingNextHop

Computes the 2-D intersection of two line segments using Cramer's rule with the determinant() helper. Returns Coord::NIL for degenerate inputs or out-of-segment intersections.

a = det(x1,y1, x2,y2)
b = det(x3,y3, x4,y4)
c = det(x1-x2, y1-y2, x3-x4, y3-y4)
x = det(a, x1-x2, b, x3-x4) / c
y = det(a, y1-y2, b, y3-y4) / c

vector<L3Address> getPlanarNeighbors()
Called by: getPlanarNeighborsCounterClockwise Supports NO_PLANARIZATION / RNG / GG

Filters the neighbour table to retain only nodes that belong to the planar subgraph under the selected algorithm. Required by perimeter routing to guarantee loop-freedom.

ModeElimination Rule
NO_PLANARIZATIONNo filtering — all neighbours kept
RNGEliminate j if ∃ witness w: dist(self,j) > max(dist(self,w), dist(w,j))

📊PLS Measurement (Post-hoc only)

Design clarification: Both calculateChannelCapacity() and calculateSecrecyCapacity() are called after the routing decision is made. They produce statistics for comparison purposes only and do not influence which neighbour is chosen.
double calculateChannelCapacity(senderPos, receiverPos)
Eq. 2/3 — Chai 2023 Called by: calculateSecrecyCapacity

Shannon capacity under Free Space Path Loss. Distance clamped to ≥ 1 m.

d = ||receiverPos − senderPos|| (min 1.0 m)
pathLoss = λ / (4π × d)
|h|² = pathLoss²
SNR = Pt × |h|² / σ²
C = log₂(1 + SNR) [bits/s/Hz]
transmitPower
Pt in watts (10 dBm default)
noisePower
σ² in watts (−174 dBm default)
wavelength
λ in metres (5.9 GHz → 0.05085 m)
flowchart TD A([calculateChannelCapacity]) --> B[d = Euclidean distance] B --> C{d < 1.0?} C -- yes --> D[d = 1.0] C -- no --> E D --> E[pathLoss = wavelength / 4*PI*d] E --> F[channelGain = pathLoss^2] F --> G[SNR = transmitPower * channelGain / noisePower] G --> H([return log2 1+SNR])
double calculateSecrecyCapacity(senderPos, nextHopPos)
Eq. 4 — Chai 2023 Uses globalPositionTable for eavesdroppers Called by: findGreedyRoutingNextHop, findPerimeterRoutingNextHop

Computes worst-case Secrecy Capacity against all globally known eavesdroppers. Uses the global table (not local) so nodes outside the eavesdropper's radio range still compute correct CS values.

Cij = calculateChannelCapacity(sender, nextHop)
for each eavesdropper e in globalPositionTable:
  Cie = calculateChannelCapacity(sender, e_pos)
  CS = max(Cij − Cie, 0)
return min(CS over all e) ← worst case
return Cij if no eavesdroppers known
flowchart TD A([calculateSecrecyCapacity]) --> B[Cij = calculateChannelCapacity sender nextHop] B --> C[eavesdroppers = globalPositionTable.getEavesdropperAddresses] C --> D[EV_WARN debug log count] D --> E{empty?} E -- yes --> F([return Cij]) E -- no --> G[minCS = Cij] G --> H[for each eavesdropper e] H --> I[ePos = getEavesdropperPosition e] I --> J[Cie = calculateChannelCapacity sender ePos] J --> K["CS = max(Cij-Cie, 0.0)"] K --> L{CS < minCS?} L -- yes --> M[minCS = CS] L -- no --> N[next e] M --> N --> H H --> O([return minCS])

L3Address findPerimeterRoutingNextHop(destination, gpsrcsOption)
GPSR Face Traversal / Right-hand rule Post-hoc CS measurement

Implements GPSR's perimeter routing on the planar graph. Two branches:

  • Branch A: If now closer to destination than start position → switch back to greedy.
  • Branch B: Compute CCW neighbour order from arrival angle. Walk edges; if an edge crosses the start→dest line, enter a new face. Select the first non-crossing edge. Detect face-cycle completion. Measure CS post-hoc.
